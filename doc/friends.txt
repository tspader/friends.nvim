1. INTRODUCTION                                                 *friends-intro*

friends.nvim shows you when your friends are in Neovim: one dot per friend
in your statusline, filled while they are active. It keeps a leaderboard
of everyone's usage, ranked by active time or keystrokes.

On first start the plugin registers you automatically: you get a public
handle (share it so friends can follow you) and a private token that proves
the handle is yours. Both are stored locally; use |:Friends key| and
|:Friends claim| to reuse the same identity on another machine. While
tracking is enabled, the plugin batches your activity into periodic
heartbeats to the backend; disable `track` to lurk.

You can ping a friend with |:Friends-ping|: a small popup appears in the
corner of their Neovim window. If the `websocat` command is installed,
pings (and activity heartbeats) travel over a persistent connection and
arrive immediately; otherwise pings ride the recipient's next activity
heartbeat instead, so they arrive within a couple of minutes and only
while that person is actually editing. Sending and receiving pings both
require a registered identity, so `track = false` (lurking) disables
pings too.

2. SETUP                                                        *friends-setup*

Calling setup() is optional; everything has defaults. Tracking starts
automatically on |VimEnter|; set `vim.g.friends_autostart = false` before
plugins load to opt out.                                  *g:friends_autostart*

The defaults: >lua

  require("friends").setup({
    -- Backend to talk to. Point this at your own worker to self host.
    url = "https://friends.spader.zone/api",
    -- Handles you follow. Merged with the ones added via :Friends add.
    friends = {},
    -- Display name pushed to the backend on startup. Overrides :Friends name.
    display_name = nil,
    -- Send activity heartbeats. Disable to lurk.
    track = true,
    -- Seconds between friend status refreshes for the statusline. 0 disables.
    status_interval = 120,
    -- Request timeout in milliseconds.
    request_timeout = 5000,
    statusline = {
      active = "●",
      idle = "○",
      separator = " ",
      -- Show each friend's name next to their dot.
      names = false,
    },
    leaderboard = {
      period = "week", -- all | week | today
      metric = "active_time", -- active_time | keys_pressed
      limit = 20,
      -- Only rank you and your friends instead of the whole world.
      friends_only = false,
    },
    ping = {
      -- Show pings from friends. Sending is unaffected by this option.
      -- Pings ride along with activity heartbeats, so they only arrive
      -- while you are tracking and editing. Pings from handles outside
      -- your roster are ignored.
      enabled = true,
      -- How long the ping popup stays on screen, in milliseconds.
      duration_ms = 4000,
    },
    ws = {
      -- Use a persistent connection (requires the `websocat` command) for
      -- instant pings and heartbeats. Falls back to polling if unset or
      -- websocat isn't installed.
      enabled = true,
    },
  })
<
==============================================================================
3. COMMANDS                                                  *friends-commands*

                                                                     *:Friends*
:Friends                Show the leaderboard. Press `a` on a row to follow
                        that person; `q` closes. Switch what is ranked
                        without closing: <Tab>/<S-Tab> cycle the period
                        through today/week/all, `p` picks one via
                        |vim.ui.select()|, `m` cycles the metric
                        (active_time/keys_pressed), and `f` toggles between
                        the global board and just you + your friends. The
                        chosen period, metric, and friends filter stick for
                        the rest of the session.
                                                              *:Friends-board*
:Friends board [value ...]
                        Show the leaderboard with the given options, e.g.
                        `:Friends board today`. Each value selects the axis
                        it belongs to — period: `today`, `week`, `all`;
                        ranking metric: `active_time`, `keys_pressed`.
                        Values complete with |cmdline-completion|.
:Friends add {handle}   Follow a friend by handle.
:Friends remove {handle}
                        Unfollow a friend.
                                                                *:Friends-ping*
:Friends ping {handle} [message]
                        Ping a friend already in your roster (|:Friends add|
                        them first). {handle} also accepts their display
                        name. If it matches more than one friend, you'll be
                        asked to use the handle instead. A small popup
                        appears in the corner of their Neovim window and
                        disappears on its own after `ping.duration_ms`.
                        Delivered instantly if `websocat` is installed and
                        connected (see |friends-setup|'s `ws` option),
                        otherwise on the recipient's next activity
                        heartbeat. Pings go stale after ten minutes.
                        Recipients ignore pings from handles that are not
                        in their own roster. Rate limited to one ping every
                        few seconds per sender.
:Friends list           Show your friends (and yourself), who is active, and
                        their hours. The window below the list shows the
                        highlighted user's last-active time and their tracked
                        stats (active time, keys pressed).
                                                               *:Friends-name*
:Friends name {name}    Set your display name. Must be a single word (no
                        spaces).
:Friends handle         Show your handle so you can share it.
                                                                *:Friends-key*
:Friends key            Show your handle + secret token, for claiming this
                        identity on another machine. Don't share it.
                                                              *:Friends-claim*
:Friends claim {handle} {token}
                        Become an existing identity (paste from
                        :Friends key on your other machine).
:Friends toggle         Pause/resume activity tracking.
:Friends delete         Delete your handle and all its data from the backend
                        (asks first). A fresh identity is created afterward.

4. STATUSLINE                                              *friends-statusline*

`require("friends").statusline()` returns a string with one dot per friend:
green and filled while they are active (highlighted via |hl-FriendsActive|),
dim and hollow otherwise. It reads from a cache and never blocks.

lualine: >lua

  sections = { lualine_x = { "friends" } }
<
plain 'statusline' (note the `%{%...%}` form, so highlights apply): >lua

  vim.o.statusline = "%f %= %{%v:lua.require'friends'.statusline()%}"
<
`statusline({ hl = false })` returns the dots without highlight escapes.

                                           *hl-FriendsActive* *hl-FriendsIdle*
Colors come from the `FriendsActive` (default: links to |hl-DiagnosticOk|)
and `FriendsIdle` (default: links to |hl-Comment|) highlight groups, used in
the statusline and the leaderboard/list windows. Override with
|nvim_set_hl()|.
==============================================================================
5. SELF HOSTING                                              *friends-selfhost*

The backend is a small Hono app on Cloudflare Workers with D1, deployed with
Terraform (which also generates `backend/wrangler.json`). See the README in
the repository root. Point `url` at your worker and you are done.
