2. SETUP                                                        *friends-setup*

Calling setup() is optional; everything has defaults. Tracking starts
automatically on |VimEnter|; set `vim.g.friends_autostart = false` before
plugins load to opt out.                                  *g:friends_autostart*

The defaults: >lua

  require("friends").setup({
    -- Backend to talk to. Point this at your own worker to self host.
    url = "https://friends.spader.zone/api",
    -- Handles you follow. Merged with the ones added via :Friends add.
    friends = {},
    -- Display name pushed to the backend on startup. Overrides :Friends name.
    display_name = nil,
    -- Send activity heartbeats. Disable to lurk.
    track = true,
    -- Seconds between friend status refreshes for the statusline. 0 disables.
    status_interval = 120,
    -- Request timeout in milliseconds.
    request_timeout = 5000,
    statusline = {
      active = "●",
      idle = "○",
      separator = " ",
      -- Show each friend's name next to their dot.
      names = false,
    },
    leaderboard = {
      period = "week", -- all | week | today
      limit = 20,
      -- Only rank you and your friends instead of the whole world.
      friends_only = false,
    },
  })
<

3. COMMANDS                                                  *friends-commands*

                                                                     *:Friends*
:Friends                Show the leaderboard. Press `a` on a row to follow
                        that person; `q` closes. Switch the ranking period
                        without closing: <Tab>/<S-Tab> cycle through
                        today/week/all, `p` picks one via |vim.ui.select()|.
                        The chosen period sticks for the rest of the session.
                                                              *:Friends-board*
:Friends board [value ...]
                        Show the leaderboard with the given options, e.g.
                        `:Friends board today`. Each value selects the axis
                        it belongs to — period: `today`, `week`, `all`;
                        ranking metric: `active_time` (more to be added).
                        Values complete with |cmdline-completion|.
:Friends add {handle}   Follow a friend by handle.
:Friends remove {handle}
                        Unfollow a friend.
:Friends list           Show your friends, who is active, and their hours.
:Friends name {name}    Set your display name.
:Friends handle         Show your handle so you can share it.
                                                                *:Friends-key*
:Friends key            Show your handle + secret token, for claiming this
                        identity on another machine. Don't share it.
                                                              *:Friends-claim*
:Friends claim {handle} {token}
                        Become an existing identity (paste from
                        :Friends key on your other machine).
:Friends toggle         Pause/resume activity tracking.
:Friends delete         Delete your handle and all its data from the backend
                        (asks first). A fresh identity is created afterward.

4. STATUSLINE                                              *friends-statusline*

`require("friends").statusline()` returns a string with one dot per friend:
green and filled while they are active (highlighted via |hl-FriendsActive|),
dim and hollow otherwise. It reads from a cache and never blocks.

lualine: >lua

  sections = { lualine_x = { "friends" } }
<
plain 'statusline' (note the `%{%...%}` form, so highlights apply): >lua

  vim.o.statusline = "%f %= %{%v:lua.require'friends'.statusline()%}"
<
`statusline({ hl = false })` returns the dots without highlight escapes.

                                           *hl-FriendsActive* *hl-FriendsIdle*
Colors come from the `FriendsActive` (default: links to |hl-DiagnosticOk|)
and `FriendsIdle` (default: links to |hl-Comment|) highlight groups, used in
the statusline and the leaderboard/list windows. Override with
|nvim_set_hl()|.

5. SELF HOSTING                                              *friends-selfhost*

The backend is a small Hono app on Cloudflare Workers with D1, deployed with
Terraform (which also generates `backend/wrangler.json`). See the README in
the repository root. Point `url` at your worker and you are done.
